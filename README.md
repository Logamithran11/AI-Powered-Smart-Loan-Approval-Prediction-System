# 📖 Project Overview

The **AI-Powered Smart Loan Approval Prediction System** is an end-to-end Machine Learning project designed to predict whether a loan application is likely to be **Approved** or **Rejected** based on applicant information.

This project demonstrates the complete Machine Learning lifecycle—from understanding and cleaning the data to training, evaluating, and comparing predictive models for intelligent decision-making.

---

# 🎯 Project Objectives

✅ Analyze loan applicant data.

✅ Perform data cleaning and preprocessing.

✅ Explore hidden insights through Exploratory Data Analysis (EDA).

✅ Build and compare multiple Machine Learning models.

✅ Predict loan approval outcomes.

---

# 📂 Dataset Information

The project uses the **Loan Prediction Dataset**, which contains applicant information such as:

- 👤 Gender
- 💍 Marital Status
- 👨‍👩‍👧 Dependents
- 🎓 Education
- 💼 Self Employment
- 💰 Applicant Income
- 💵 Co-Applicant Income
- 🏦 Loan Amount
- 📅 Loan Amount Term
- 📈 Credit History
- 🏡 Property Area
- ✅ Loan Status (Target Variable)
